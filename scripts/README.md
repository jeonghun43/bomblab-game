# 대본 md 작성법

이 폴더의 `*.md` 파일이 **게임 대본의 원본**입니다. 게임은 실행할 때 이 파일을 직접 읽어서 장면, 대사, 조사, 레슨, 퀴즈를 만듭니다(`scriptmd.js`가 해석). 대사나 과제를 바꾸고 싶으면 코드가 아니라 이 파일을 고치세요.

- 게임이 읽는 섹션: `## 설정`, `## 캐릭터`, `## 용어`, `## 해독기 풀이`, `## 대본`
- 그 밖의 섹션(`## 커리큘럼`, `## 말투` 등)과 `>`로 시작하는 줄, `|` 표는 **사람을 위한 메모**라서 게임이 무시합니다. 어떤 개념을 왜 이 순서로 가르치는지는 여기에 적으세요.
- 고친 뒤에는 `tests/test.html`을 열어 전부 PASS인지 확인하세요. 대본 검증과 레슨 모범답안 시뮬레이션이 들어 있습니다.

## 설정

```
- id: defuse
- 이름: 폭탄 해체반
- 키커: EOD UNIT · 신입 교육        ← 제목 위 작은 글씨
- 소개: …                          ← 선택 화면 카드 문구
- 표지: server                      ← 선택 화면 썸네일 장소
- 안내역: chief                     ← 터미널 위에 나오는 캐릭터
- 튜토리얼: 예                      ← 예면 명령 잠금·해독기 켜짐
- 레벨: calc, 1                     ← 이 이야기가 쓰는 퍼즐(levels.js의 id)
- 카운트다운: 600                   ← 초. 튜토리얼에서는 `타이머: 예`인 레슨에서만 돎
- 용어.카드 / 용어.단서 / 용어.점수 / 용어.단계
- 브리핑.0: …                       ← (튜토리얼이 아닐 때) 퍼즐별 터미널 첫 대사
- 폭발: …                           ← 여러 줄 가능. 폭발 횟수 순서대로 나옴
- 오답: … / 힌트머리: 무전: / 잠긴도구: … / 엔딩제목: …
- 엔딩문구: …                       ← 결과 화면에 나오는 안내 한 줄
```

## 말투 (사람용 메모, 게임은 안 읽음)

캐릭터가 쓰는 종결어미를 표로 적어 두고 대본 전체에 지킵니다. 폭탄 해체반은 "~다."로 끝내지 않는 반장 구어체를 쓰고, 테스트가 이를 검사합니다([defuse.md](./defuse.md)의 `## 말투`).

## 용어

```
- 레지스터: CPU 안에 있는 아주 작고 빠른 칸인 거야. …
```
대사 속 `[[레지스터]]`를 누르면 이 풀이가 뜹니다. 대사에 `[[ ]]`로 쓴 용어는 반드시 여기에 있어야 합니다(테스트가 검사).

## 해독기 풀이

```
- mov: "넣어라"란 말이지. 왼쪽 값을 오른쪽 칸에 넣는 거야.
```
해독기에서 단어를 눌렀을 때 나오는 설명입니다. 키(`mov`, `esi` 등)는 `decoder.js`의 토큰 표에 있는 이름을 씁니다.

## 캐릭터

```
- chief: 반장 (초상화 chief)
- voice: ???                        ← 초상화 없는 목소리
```
대사에서는 **표시 이름**을 씁니다. 예: `반장: 안녕`. 캐릭터 없이 쓰려면 `내레이션: …`.

## 대본 (위에서 아래로 순서대로 진행)

| 쓰는 법 | 의미 |
|---|---|
| `### 장면: van` | 장소 전환 (art.js의 장면 id) |
| `반장: 대사` | 대사 한 줄. 클릭하면 다음 줄 |
| `[[레지스터]]` | 대사 속 용어. 누르면 glossary.js의 풀이가 뜸 |
| `### 조사: 목표 문구` | 조사 단계 시작. 아래에 `####` 사물들 |
| `### 대사` | 조사 블록을 끝내고 다시 일반 대사로 돌아올 때 |
| `### 퀴즈` | 대사창 퀴즈. `화자:` `질문:` `보기:` `정답:` `오답:` |
| `### 해독기: addr, reg` | 개념을 배웠다고 표시하고 해독기를 연다. `설명:`으로 한 줄 |
| `### 플래그 켜기: 이름` / `### 플래그 끄기: 이름` | 장면 그림을 바꾸는 플래그 (art.js의 `draw`가 읽음) |
| `### 엔딩` | 결과 화면 |

`보기: 3 | *8 | 53` 처럼 **정답 앞에 `*`**를 붙입니다.

### 사물 (`### 조사` 아래)

```
#### 살펴보기 note@map: 지도 옆 쪽지     ← 종류 id@장면좌표: 라벨 (id를 안 쓰면 장면좌표가 id)
단서: 제목 | 내용                       ← 수첩에 추가됨
끝: 예                                  ← 이걸 보면 조사 단계가 끝남
반장: 사물을 눌렀을 때 대사

#### 컴퓨터 laptop: 노트북               ← 누르면 터미널이 열림
레벨: 1
필요: note, manual                     ← 먼저 봐야 하는 사물 id
잠김:
반장: 필요한 걸 안 봤을 때 대사
레슨: calc                              ← (선택) 튜토리얼 레슨
세션: calc                              ← 같은 세션이면 터미널 상태(breakpoint 등)가 이어짐
타이머: 예                              ← 카운트다운 사용
벌점: 예                                ← 폭발·오답 감점 (연습 레슨에서는 쓰지 말 것)
##### 과제 …                            ← 레슨 과제들 (아래)
해제 후:
반장: 레슨/퍼즐을 끝낸 뒤 대사

#### 출구 door: B-03 문                  ← 누르면 조사 단계가 끝남
```
종류는 `살펴보기`, `컴퓨터`, `출구` 세 가지입니다.

### 레슨 과제 (`#### 컴퓨터` 아래, `레슨:` 다음)

```
##### 과제
도구: break                     ← 이 과제에서 새로 여는 명령 (run, break, continue, stepi, print, info, x, disassemble)
보이기: 레지스터 rax rdi, 코드    ← 오른쪽 패널 공개 (레지스터 칸 목록 / 디스어셈블리)
반장: 캐릭터가 하는 말
목표: 왼쪽 "지금 할 일"에 보이는 문구
예시: break phase_1              ← 입력칸의 흐린 글씨 + 추천 명령 (도움을 줄이려면 생략)
힌트: hint 명령을 쳤을 때 알려 줄 말
완료: event=break at=phase_1     ← 이 조건이 되면 다음 과제로

##### 예측
질문: 실행하면 rax는?
보기: 3 | *8 | 53
정답: 맞혔을 때 말
오답: 틀렸을 때 설명

##### 확인: 알겠다                 ← 버튼 하나. 설명만 하고 넘어갈 때
반장: 설명
```

`완료:` 조건은 공백으로 여러 개를 쓰면 **모두** 만족해야 합니다. 값에 공백이나 특수문자가 있으면 `` `백틱` ``으로 감쌉니다.

| 조건 | 뜻 |
|---|---|
| `event=input` | 프로그램이 입력을 기다리기 시작함 |
| `event=break at=phase_1` | phase_1에서 멈춤 |
| `event=exploded` / `event=defused` | 폭발 / 해체 |
| `reg=rax eq=5` | rax 칸이 5 |
| ``cmd=`^x/s` `` | 입력한 명령이 정규식과 맞음 |
| ``out=`Registers never lie` `` | 명령 출력에 이 글자가 있음 (오류 출력으로 통과하는 걸 막을 때) |
| `running` | 프로그램이 실행 중 |
| `answer` | `answer` 명령으로 정답을 냄 |

새 레슨을 추가하면 `tests/test.html`의 `MODEL`(과제별 모범 명령)에도 한 줄 추가하세요. 테스트가 "모범 명령을 치면 모든 과제가 통과되는지"를 확인합니다.

## 퍼즐 글: `puzzles.md`

이야기 md와 별도로, 여러 이야기가 함께 쓰는 **퍼즐의 글**은 [puzzles.md](./puzzles.md)에 있습니다. 어셈블리 코드, 메모리 속 문자열, 정답 판정, 프로그램 출력(영어)은 `levels.js`에 있습니다.

```
## 도구함
- break: break 이름 | 그 이름의 함수에 닿으면 멈춤     ← 명령이름: 쓰는 법 | 설명

## 퍼즐: calc                       ← levels.js의 퍼즐 id (1, calc)
제목: 훈련 · 계산기
목표: `%rdi` 칸에 남는 숫자를 `answer <숫자>`로 제출하세요.
추천 명령: break calc, run, si, p $rdi     ← 터미널 왼쪽 "추천 명령" (튜토리얼이 아닐 때)
힌트: 첫 번째 hint                   ← 여러 줄 가능. 튜토리얼 레슨에서는 과제의 `힌트:`가 우선
힌트: 두 번째 hint

### 카드: 레지스터: CPU의 작업대 칸   ← 퍼즐을 풀면 나오는 개념 카드
- **레지스터**는 CPU 안의 작은 칸입니다.
- `mov $0x5,%rax`: rax 칸에 5를 넣어라.
```
글 안에서 `` `코드` ``는 코드 글꼴, `**굵게**`는 굵은 글씨가 됩니다. 새 퍼즐을 추가하면 `levels.js`에 같은 id로 코드와 정답 판정을 넣고, 여기에 `## 퍼즐: id` 섹션을 만드세요. 섹션이 없으면 게임이 시작할 때 오류를 냅니다.
